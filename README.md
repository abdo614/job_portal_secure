# Job Portal Secure

نظام بوابة توظيف متكامل وآمن مبني بـ Flask مع تشفير AES-256 للبيانات المخزنة.

## المميزات الرئيسية

- **لوحة إدارة شاملة** لإدارة المستخدمين والوظائف والإعدادات
- **نظام توظيف كامل**: نشر وظائف، تقديم طلبات، حفظ مفضلة
- **محفظة رقمية (Wallet)** للدفعات والاشتراكات
- **فواتير إلكترونية** وربط ببوابات دفع
- **دعم ثنائي اللغة** (عربي / English)
- **بوت تيليجرام** للتنبيهات والتسجيل
- **تشفير AES-256** لجميع البيانات الحساسة المخزنة
- **نظام CMS** لإدارة المحتوى والخدمات والأسئلة الشائعة
- **النسخ الاحتياطي التلقائي** للبيانات المشفرة

## المتطلبات

- Python 3.8+
- pip

## التشغيل

```bash
# 1. تثبيت المتطلبات
python -m pip install -r requirements.txt

# 2. إعداد متغيرات البيئة (انسخ .env.example إلى .env)
cp .env.example .env

# 3. تشغيل التطبيق
python app.py
```

ثم افتح المتصفح على: `http://localhost:5000`

## إعداد الإنتاج

```bash
python run_production.py
```

> يُستخدم `run_production.py` للتشغيل في بيئة إنتاج آمنة مع HTTPS.

## متغيرات البيئة

| المتغير | الوصف | مطلوب |
|---------|-------|-------|
| `SMTP_HOST` | خادم البريد الصادر | للتسجيل/التحقق |
| `SMTP_PORT` | منفذ البريد الصادر | للتسجيل/التحقق |
| `SMTP_USER` | بريد المرسل | للتسجيل/التحقق |
| `SMTP_PASSWORD` | كلمة مرور تطبيق البريد | للتسجيل/التحقق |
| `MAIL_FROM` | البريد الظاهر في المرسل | للتسجيل/التحقق |
| `FLASK_SECRET_KEY` | مفتاح سرية Flask (يجب تغييره) | نعم |
| `FLASK_HTTPS` | تفعيل HTTPS (1/0) | اختياري |
| `TELEGRAM_BOT_TOKEN` | توكن بوت تيليجرام | لبوت تيليجرام |

## الأمان

- **جميع البيانات** تُخزن مشفرة بـ AES-256 في مجلد `data/`
- **كلمات المرور** مشفرة بـ bcrypt
- **مفتاح التشفير** في `data/.key` — **لا تقم أبداً برفعه أو حذفه**
- يُنشأ حساب مدير افتراضي عند أول تشغيل، وكلمة المرور تُعرض مرة واحدة في السجل

